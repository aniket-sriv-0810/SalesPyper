# 🧩 Mini Task Management Dashboard

A modern and responsive **Task Management Dashboard** built with **React** and **Tailwind CSS** as part of a frontend intern assignment. This dashboard allows users to view, filter, assign, and manage tasks interactively, with a beautifully styled UI, glassmorphism, and persistent local state.

**Live Demo**: (https://your-deployment-url.com)


---

## 🧠 Features

- ✅ **Login Simulation** – Dummy login to route users into the dashboard
- 📊 **Summary Cards** – View total, completed, and pending tasks
- 🧾 **Tasks Table** – Search, filter, and update task status inline
- 👤 **Assign Modal** – Assign tasks to users via a styled popup modal
- 🎨 **Eye-Catching UI** – Glassmorphism, gradient backgrounds, hover animations
- 📱 **Fully Responsive** – Seamlessly works across devices
- 💾 **LocalStorage Support** – Tasks persist even after page reload

---

## 🛠 Tech Stack

- ⚛️ **React**
- 💨 **Tailwind CSS**
- 💡 **React Icons**
- 🧠 **Context API**
- 🗂 **LocalStorage** for persistent state
